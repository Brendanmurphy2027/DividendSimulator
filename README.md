# Dividend Simulator
The Dividend Simulator is a Python command-line project that models the growth of an investment through dividend reinvestment over time. It allows users to input the number of starting shares, the current share price, the annual dividend yield, and the number of years to simulate. The program then calculates yearly dividend income, automatically reinvests it into new shares, and displays the results after each simulated year. Once the simulation is complete, it summarizes the starting portfolio value, final number of shares, final portfolio value, and total growth rate, helping users visualize the impact of compound reinvestment. In addition to showing results in the console, the program also generates a text file named dividend_yield.txt that contains a detailed summary of the simulation results, making it easy to review or share later. The Dividend Simulator is simple, portable, and perfect for investors or learners who want to better understand dividend reinvestment and compounding in a hands-on way.
